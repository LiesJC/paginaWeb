Redes de Computadoras

Aprende los fundamentos de las redes informáticas

Tipos de Redes

LAN

Red de área local utilizada en hogares, oficinas y laboratorios.

MAN

Red que conecta diferentes zonas dentro de una ciudad.

WAN

Red que conecta dispositivos ubicados en grandes distancias.

WLAN

Red local que utiliza tecnologías inalámbricas como Wi-Fi.

Topologías de Red

Estrella

Los dispositivos se conectan a un dispositivo central.

PC ──┐
PC ──┼── SWITCH
PC ──┘

Bus

Todos los dispositivos comparten un medio de transmisión.

PC ─── PC ─── PC

Anillo

Los dispositivos forman una conexión cerrada.

PC → PC → PC → PC

Malla

Los dispositivos poseen múltiples conexiones entre ellos.

Dispositivos de Red

Dispositivo Función
Router Conecta diferentes redes y dirige paquetes.
Switch Conecta dispositivos dentro de una LAN.
Access Point Permite conexiones inalámbricas.
Firewall Controla y filtra el tráfico de red.

Protocolos de Red

HTTP

Protocolo utilizado para la comunicación entre navegadores y servidores web.

HTTPS

Permite comunicación web protegida mediante cifrado.

TCP/IP

Conjunto fundamental de protocolos utilizados en Internet.

DNS

Traduce nombres de dominio a direcciones IP.
